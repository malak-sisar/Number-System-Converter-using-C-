# Number System Converter

A C++ program that converts numbers between different number systems:
Decimal, Binary, Octal, and Hexadecimal.

## Features

The program provides 12 conversion options:

1. Decimal to Binary
2. Decimal to Octal
3. Decimal to Hexadecimal
4. Binary to Decimal
5. Binary to Octal
6. Binary to Hexadecimal
7. Octal to Decimal
8. Octal to Binary
9. Octal to Hexadecimal
10. Hexadecimal to Decimal
11. Hexadecimal to Binary
12. Hexadecimal to Octal

## Input Validation

The program checks whether the entered number is valid for the selected number system.

- Binary numbers can contain only `0` and `1`.
- Octal numbers can contain digits from `0` to `7`.
- Hexadecimal numbers can contain digits from `0` to `9` and letters from `A` to `F`.

## Technologies Used

- C++
- iostream
- string

## How to Run

1. Compile the `main.cpp` file using a C++ compiler.
2. Run the program.
3. Choose a conversion option from the menu.
4. Enter the required number.
5. The program displays the converted result.
